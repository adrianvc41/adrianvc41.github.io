Ejercicio 07 — Introducción de datos y toma de decisiones

Este programa pregunta al usuario si quiere jugar. Si responde "s", le pide que escriba el nombre de una fruta y, según la fruta que introduzca, muestra un mensaje con su precio utilizando una estructura `switch`. Después le hace una segunda pregunta para saber si quiere consultar algo más y muestra una respuesta dependiendo de lo que conteste. Si el usuario responde que no quiere jugar, el programa termina mostrando un mensaje diferente.
